
# ITIL 4 (Concept)
## Description
ITIL (a.k.a Information Technology Infrastructure Library) is a framework with a set of practices (formerly processes) for information technology (IT) activities such as IT service management (ITSM) and IT asset management (ITAM) that focus on aligning IT services with the needs of a business.
